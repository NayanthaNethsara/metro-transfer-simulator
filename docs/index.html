About & Model Rules

Client-side port (docs/sim-engine.js) using notebook-calibrated alpha factors, OSM/OSRM geometry (docs/corridor-geo.js), and 5-band cmb_traffic Markov speeds (docs/config.js).

  • Inspection: Click any bus, table row, or log item to jump to that Borella event.
  • Dwell: (12 + 2 * alight + 2 * board) / 60 min.
  • Traffic: 3-state DTMC (30-min slots; peaks 07:00–09:00, 16:00–19:00; free before 05:00).
  • Queueing: FCFS Borella boarding; patience 20 min, ticket validity 120 min.
  • Objective J: 2.0 * (walk + wait + 60m lost penalty) + 1.0 * hold pax-min.
  • Check: Preset runs compare Mean Missed against R=1000 notebook references (±2.0 pp).
